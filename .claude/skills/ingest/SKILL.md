# 자료 추가

1. `python tools/extract.py [과목]` 실행. 인자로 과목이 주어지면 그 과목만.
2. 출력에서 `⚠ 스캔본` 경고가 있으면 알려주고, 해당 파일은 질문할 때 원본 PDF를 직접 읽게 된다고 설명한다.
   `[미지원]`이 있으면 PDF로 변환하는 방법(PowerPoint/한글에서 "PDF로 저장")을 안내한다.
3. 새로 추출된 파일마다 `texts/`의 내용을 읽고 아래 형식으로 짧게 정리한다:
   - **파일명**: 다루는 주제 한 줄
   - 핵심 개념 3~7개 (출처 페이지 포함)
4. 마지막에 "이 자료로 퀴즈를 낼까요?"라고 한 번 묻는다.
