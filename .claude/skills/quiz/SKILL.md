# 퀴즈

## 1. 범위 정하기
- 인자에서 과목, 범위(강/파일), 문제 수를 읽는다. 없으면 기본 5문제로 하고, 과목·범위만 짧게 물어본다.
- 범위에 해당하는 `texts/` 파일을 읽는다.
- `python tools/srs.py stats <과목>`으로 "자주틀린주제"를 확인하고, 범위 안에 있으면 1~2문제를 그 주제에서 낸다.
- **시험 스타일**: `data/styles/<과목>.note.txt`(내가 적은 교수님 출제 스타일, 가장 우선)와 `data/styles/<과목>.json`의 `guide`(시험 자료 분석)가 있으면 읽고, 그 유형 비율·말투·소문항 구조·배점 표시대로 실제 시험지처럼 낸다. 내가 "일반 문제로"라고 하면 따르지 않는다.

## 2. 출제
- 문제 유형을 섞는다: 개념 설명형, 비교형("A와 B의 차이"), 적용형(상황/계산), 객관식 약간.
- **모든 문제는 자료에 근거해야 하며, 정답과 출처 페이지를 미리 정해둔다.** 자료에 없는 내용은 내지 않는다.
- **한 번에 한 문제씩** 내고 내 답을 기다린다. 정답을 미리 보여주지 않는다.

## 3. 채점 (문제마다)
- 맞음 / 부분정답 / 틀림으로 판정하고, 왜 그런지 1~3줄로 설명 + 출처 `(파일 p.N)`.
- 부분정답이면 빠진 핵심 키워드를 짚는다.
- 틀림 또는 부분정답이면 그 문제를 기록해둔다.

## 4. 마무리
- 점수와 틀린 주제를 요약한다.
- 틀린/부분정답 문제를 한 장씩 카드로 저장한다 (질문은 다시 풀 수 있는 형태로, 답은 핵심만):
  `python tools/srs.py add --subject "과목" --topic "주제" --question "질문" --answer "답" --source "파일 p.N" --lapses 1`
- 저장된 카드는 내일부터 `/review`로 복습할 수 있다고 알려준다.
