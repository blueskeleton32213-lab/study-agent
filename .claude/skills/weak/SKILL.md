# 약점 분석

## 1. 기록 모으기
앱에서 부르면 요청 메시지에 `[공부 기록]`이 이미 붙어 있다 → 그걸 쓰고 스크립트는 돌리지 않는다.
없으면 `python tools/studylog.py <과목>` 한 번 실행 (과목을 안 줬으면 대화의 [현재 과목]). 기록에는 세 가지가 있다:
- **복습 카드**: 헷갈린 순서. 카드는 대부분 퀴즈에서 틀려서 만든 것이고, 평가 숫자(1 다시·3 어려움)가 있으면 복습에서도 막힌 것
- **질문하기 대화**: 내가 직접 물은 질문 (같은 대화 안의 이어 묻기는 헷갈렸다는 신호)
- **질문 창 대화**: 퀴즈·정리 자료·답변에서 드래그해서 물은 것. «드래그한 부분»이 막힌 지점

세 가지가 모두 비어 있으면 "퀴즈를 풀거나 질문을 해보면 분석할 수 있어요"라고 하고 끝낸다.

## 2. 판단하기 (자료를 읽기 전에 기록만으로)
**부족한 개념** — 같은 개념이 여러 곳에서 나오면 약점이다. 카드 주제 + 질문에 나온 개념을 묶는다 (예: 카드 "LSTM-파라미터 수" + 질문 "LSTM 가중치가 총 8개야?" → LSTM 게이트·가중치).

**부족한 유형** — 문제·질문을 아래 유형으로 나눠 어디서 많이 막히는지 본다:
| 유형 | 예 |
|---|---|
| 정의·개념 이해 | "~가 뭐야", 객관식 옳은 설명 고르기 |
| 비교·차이 | "BPE랑 BERT 차이", LDiA vs LSA |
| shape·차원 추적 | 텐서·행렬 shape, 파라미터 수 |
| 손계산 | 손실값, hidden state, 합성곱 값 |
| 수식·유도 | 식의 의미, 식 세우기 |
| 흐름·과정 | 학습·생성 순서, 알고리즘 단계 |
| 코드 | PyTorch·scikit-learn 구현, 출력 shape 주석 |

과목에 맞지 않는 유형은 빼고, 필요하면 유형을 더한다. 근거 없는 추측은 하지 않는다 — 각 판단 옆에 근거(카드 주제·질문)를 짧게 단다.

## 3. 자료로 다시 정리
상위 개념 3~5개만 `texts/<과목>/`에서 찾아 읽고 (CLAUDE.md의 찾기·읽기 규칙대로, 필요한 부분만):

### 출력 형식
**한눈에** (표 2개)
- 부족한 개념: 개념 | 근거(카드 n장·질문 n개, 대표 예 1개) | 다시 볼 쪽
- 부족한 유형: 유형 | 막힌 횟수 | 대표 예 | 이렇게 연습

**개념별 정리** — 상위 개념마다:
- **개념** — 어디서 막혔는지 (카드·질문 근거)
- 내가 헷갈리는 포인트 한 줄
- 자료 기반 핵심 정리 3~5줄 (문장마다 출처)
- 다시 볼 페이지 목록

**유형별 팁** — 가장 약한 유형 1~2개에 대해 푸는 순서·자주 하는 실수 2~3줄.

마지막에 "이 개념들(또는 이 유형)로 퀴즈를 낼까요?"라고 묻는다.
