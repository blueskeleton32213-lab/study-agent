# 약점 정리

1. `python tools/srs.py stats [과목]` 실행.
2. 카드가 없거나 틀린 기록이 없으면 `/quiz`부터 해보자고 하고 끝낸다.
3. "자주틀린주제" 상위 3~5개에 대해 `python tools/srs.py list <과목>`에서 해당 카드들을 보고, 내가 **어떤 식으로 틀렸는지** 패턴을 찾는다 (개념 혼동, 용어만 기억, 계산 실수 등).
4. 주제마다 `texts/`에서 관련 부분을 다시 찾아 읽고 아래 형식으로 정리한다:
   - **주제** — 틀린 횟수
   - 내가 헷갈리는 포인트 한 줄
   - 자료 기반 핵심 정리 3~5줄 (출처 포함)
   - 다시 볼 페이지 목록
5. 마지막에 "이 주제들로 퀴즈를 낼까요?"라고 묻는다.
