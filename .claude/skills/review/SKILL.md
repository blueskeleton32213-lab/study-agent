# 복습

1. `python tools/srs.py due [과목] --limit 20` 실행. 비어 있으면 "오늘 복습할 카드 없음"이라고 하고, 다음 복습 예정이나 `/quiz`를 제안한 뒤 끝낸다.
2. 카드를 **한 장씩** 질문만 보여주고 내 답을 기다린다. (몇 장 남았는지 `[3/12]`처럼 표시)
3. 내 답을 카드의 answer와 비교해 채점하고 0~5점을 정한다:
   - 5: 완벽, 바로 답함 / 4: 맞음 / 3: 핵심은 맞지만 빠진 게 있음
   - 2: 틀렸지만 정답 보니 기억남 / 1: 틀림 / 0: 전혀 모름
   - 내가 "모르겠어"라고 하면 0점.
4. 정답과 짧은 설명(필요하면 `texts/`의 출처 부분을 다시 읽어서)을 보여주고, `python tools/srs.py grade <ID> <점수>` 실행.
5. 끝나면 맞은 수/전체, 여전히 약한 주제를 한 줄로 요약한다.
